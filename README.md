# 月光牧场 · Moon Ranch

手机浏览器里玩的网页版《牧场物语》。零依赖、零构建、纯 Canvas 像素风 —— 双击 `index.html` 就能玩，也可以丢到任意静态服务器 / Cloudflare Pages 上。

> 当前版本 **v1.2.1**

## 快速开始

```bash
# 方式一：双击 index.html 直接进入开始页（标题 → 新游戏 / 读档 / 说明 / 设置）
# 方式二：起个静态服务（推荐，file:// 下各页面 localStorage 互相隔离）
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

- 开始页 `index.html`：选存档槽开新局 / 读档 / 游戏说明 / 设置（音效、点地自动走、地块网格、自动存档、摇杆大小、清空存档）。
- 游戏页 `game.html?slot=1`：游戏本体，`&new=1` 强制新开。

## 玩法

核心循环是 **锄地 → 播种 → 浇水 → 收获 → 卖钱**。

| 步骤 | 工具 | 说明 |
| --- | --- | --- |
| 翻地 | 锄头（1） | 对着土块按「使用」，变成耕地 |
| 播种 | 双手（2） | 对着耕地按「使用」，消耗背包里该季的种子 |
| 浇水 | 水壶（3） | **每天要浇一次**，不浇水不长 |
| 收获 | 双手（2） | 成熟后（头顶水滴感叹号）收割，有概率掉种子 |
| 睡觉 | — | 走到屋子门口按「使用」；作物成长、动物产出、体力回满、进入第二天 |
| 买卖 | — | 走到商店柜台前按「使用」，买种子 / 卖作物、蛋、奶、羊毛 |
| 采集 | 斧头（4）/ 镐子（5） | 砍树得木材，敲石得石头 |
| 收动物 | 双手（2） | 围栏里的鸡、牛、羊每天产东西，走近按「使用」收取 |

**作物表**（11 种，每季 3 种；换季时未成熟的作物会枯死）

| 季节 | 作物 | 种子价 | 售价 | 成熟天数 |
| --- | --- | --- | --- | --- |
| 春 | 芜菁 | 30 | 75 | 3 |
| 春 | 土豆 | 40 | 110 | 4 |
| 春 | 草莓 | 60 | 180 | 5 |
| 夏 | 番茄 | 50 | 130 | 4 |
| 夏 | 玉米 | 70 | 200 | 5 |
| 夏 | 菠萝 | 90 | 260 | 6 |
| 秋 | 茄子 | 60 | 170 | 5 |

| 秋 | 南瓜 | 100 | 290 | 6 |

> 冬季只有 2 种作物可种，是刻意的（冬季作物少、售价高，逼玩家攒钱跟春季节奏）。

**规则**

- 每季 8 天，一年 4 季（春夏秋冬）。
- 体力用完只能睡觉，每推进一天体力上限略增。
- 3 个存档槽，自动存档 + 手动存档，进度存在浏览器 localStorage。

## 时间与操作手感

- **时间流速**：现实 1 秒 = 游戏 1 分钟（一天 22 小时 ≈ 22 分钟真实时间）。到 22 点提示「天黑了，回屋睡觉吧」并强制结算。
- **作用格对齐**：角色**面前那一格**才是作用目标（脚下一格 + 朝向偏移 1 格），该格会显示**黄色呼吸高亮框**，每帧实时更新，按「使用」不会挖错格。
- 工具键带 `1~5` 序号角标，不用盲按。

## 操作

| 平台 | 移动 | 交互 |
| --- | --- | --- |
| 手机 | 左下摇杆 / 点地面自动寻路 | 右下「使用」键 / 点工具格 |
| 电脑 | WASD / 方向键 | 空格 或 E 使用；数字键 1~5 切工具；B 背包；Esc 菜单 |

## 文件结构

```
ranch-moon/
├── index.html          开始页（标题、新游戏、读档、说明、设置）
├── game.html           游戏页（Canvas 容器，按依赖顺序加载脚本）
├── css/style.css       开始页 & 游戏页样式
└── js/
    ├── config.js       常量：分辨率、瓦片、11 种作物、季节配色、工具
    ├── utils.js        RNG、插值、提示条、粒子
    ├── core.js         应用版本、Settings 设置、Save 多槽位存档
    ├── audio.js        WebAudio 极简音效（可关）
    ├── state.js        全局状态、地图生成、动物、出生点、存档打包
    ├── world.js        地图查询、背包/种子、交互目标、使用道具、日子推进
    ├── render.js       瓦片/作物/动物/玩家绘制、地图烘焙、HUD、控件、弹窗
    ├── ui.js           布局计算、弹窗入口、重置 / 清空存档
    ├── game.js         主循环、指针/键盘输入、分辨率自适应、启动引导
    └── start.js        开始页逻辑（槽位、弹窗面板、跳转游戏页）
```

数据流：`state.js` 持有唯一状态源（`S` / `map` / `cropMap` / `animals`），`world.js` 改状态，`render.js` 只读绘制，`game.js` 驱动帧循环与输入。

⚠️ 开始页只加载 `core.js` + `start.js`，**不要引 `config.js`** —— `config.js` 顶层就有 `document.getElementById('cv')`，加载即抛错。

## 技术要点

- 逻辑分辨率 388~480 × 视口高，整数倍 `SCALE` 缩放 + `image-rendering: pixelated`，像素锐利、中文不糊。
- 静态地图烘焙到离屏 canvas，只在季节 / 工具改动 / 地形变化时重绘。
- 触屏 `pointerdown` + `setPointerCapture`，拖拽区 `touch-action: none`，防误触、防页面滚动。
- 存档为 JSON（含地图 2D 数组），`?slot=N&new=1` 走新游戏，否则读档；切后台 / 关页面自动存一次。
- 全局 `let`/`const` 跨 `<script>` 共享，**拆模块后必须扫一遍跨文件重复顶层声明**，否则运行时 `Identifier already declared`。
- 开始页用 bottom-sheet 弹窗（点按钮才出浮层，菜单常驻），`#app` 溢出方案用 `align-items:center` + `.stage{margin:auto}` + `overflow-y:auto`，别用 `justify-content:center`（超高内容会溢出到顶部滚不到）。

## 更新日志

### v1.2.1

- **时间流速修正**：新增 `REAL_SEC_PER_MIN = 1`（现实 1 秒 = 游戏 1 分钟），替换原来的 `HOUR_SEC` 口径；实测 4s 真实 = 4.00 游戏分钟。
